# S55 — Tối ưu tốc độ tải giao diện v2
- Nguồn: phản hồi của chủ web (2026-11-12): trang vào chậm, hiệu ứng vào sau ~1s, cảm giác lag.

## Chẩn đoán (đo bằng trình duyệt thật)
- Server nhanh (~30ms). Chậm do 5 tên miền CDN chặn vẽ (CSS xong ~2,3s, DOMContentLoaded ~3,5s), hiệu ứng hero/AOS chờ JS CDN, chuyển trang làm mờ trang cũ.

## Thay đổi
- [x] `public/vendor/` (bootstrap, fontawesome+woff2, swiper, sweetalert2, fonts) + preload phông + cache 30 ngày bất biến.
- [x] `layouts/main.ejs`: nhánh v2 dùng vendor, không AOS; nhánh classic giữ nguyên.
- [x] `theme-v2.js`: bộ hiện dần thay AOS (chỉ phần tử dưới màn hình, 0,45s); `theme-v2.css`: chuyển trang 0,16s, không mờ trang cũ.
- [x] `home-v2.css`: hero animate bằng CSS thuần (0,5s), chống giật bố cục; `home/index.ejs`: ảnh slide sau `fetchpriority=low` thay vì lazy.
- [x] Footer: ảnh logo ngoài tải lười.
- [x] `tests/s55-performance.test.js` (12 kiểm tra); sửa 2 test cũ cho khớp (hero ảnh, so sánh script classic/v2).

## Kết quả
- DOMContentLoaded 3510ms → ~415ms; CSS chặn vẽ 2314ms → ~225ms. 12/12 test S55 + toàn bộ test S43–S54 đạt.

## Chưa làm / lưu ý
- Ảnh hero mặc định từ Unsplash và ảnh Cloudinary chưa dùng `f_auto,q_auto`; nên đăng banner thật và áp `optimizeImageUrl` cho ảnh sản phẩm/banner (đề xuất).
- Nginx production nên bật gzip/brotli cho `/vendor` (xem docs/14).
