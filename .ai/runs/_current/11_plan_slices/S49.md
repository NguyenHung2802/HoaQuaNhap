# S49 — Vận hành VPS 1GB (swap, PM2, Nginx, cache menu, sao lưu)

## Goal
Web + PostgreSQL + n8n + Nginx chạy ổn trên VPS 1 vCPU/1GB RAM/20GB SSD: giảm tải DB và RAM trong mã, cấu hình PM2 an toàn cho n8n, và có hướng dẫn/công cụ vận hành.
