## Triển khai / Rollback
- Deploy: backup DB → `npx prisma migrate deploy` → `npx prisma generate` → `npx prisma db seed` (hoặc đặt các Setting `news.*` bằng tay) → `pm2 restart WebHoaQua-Prod`.
- Kiểm tra sau deploy: `SELECT post_type, count(*) FROM "BlogPost" GROUP BY 1;` phải ra toàn `blog`.
- Rollback (chưa có dữ liệu news): `DROP TABLE "NewsStatDaily"; DROP TABLE "ApiKey"; ALTER TABLE "BlogPost" DROP COLUMN ...` (các cột trong migration.sql), rồi xóa dòng khỏi `_prisma_migrations`.
